# Custom String Class Implementation in C++

## Project Description

This project focuses on developing a user-defined `STRING` class in C++ to perform basic string operations without depending on built-in string manipulation functions.

Dynamic memory allocation is used to manage string data, while constructors, destructors, deep copying, and operator overloading are implemented to handle string objects efficiently.

## Key Concepts

- Dynamic memory management using pointers
- Default and parameterized constructors
- Destructor for releasing allocated memory
- Copy constructor and deep copy mechanism
- Operator overloading
- User-defined string handling functions

## Functionalities

- Creating and managing string objects
- Allocating and freeing memory dynamically
- Copying string objects independently
- Performing string operations through overloaded operators
- Implementing string manipulation logic without standard string functions

## Development Environment

- **Language:** C++
- **Compiler:** GCC (G++)
- **Concepts:** Object-Oriented Programming and Dynamic Memory Allocation

## Project Structure

- `main.cpp` – Contains the custom STRING class implementation and main function.
- `.gitignore` – Specifies files excluded from version control.
- `README.md` – Project documentation.

## Compilation and Execution

Compile the source file:

```bash
g++ main.cpp -o main
```

Execute the program:

```bash
./main
```
